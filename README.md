# T3 Code Dark Theme

A dark theme for Visual Studio Code that uses the colors from T3 Code.

> This project is not affiliated with or endorsed by T3 Code. It only borrows T3 Code's colors to make a VS Code theme.

## Credits

## Install

Needs Node.js and the `code` command on your PATH (in VS Code: **Shell Command: Install 'code' command in PATH**).

```sh
npm run install-theme
```

Then in VS Code, press `Cmd+K` `Cmd+T` and pick **T3 Code Dark**.
